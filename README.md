# Projet LoRaWan

Projet de ZZ3 pour concevoir un capteur de température industriel avec une plateforme de visualisation des données.

Élèves :
- Adam Ibnouzahir

Prérequis :

- Le firmware doit être sécurisé avec des communications chiffrés de bout en bout du capteur à l'application.
- Les crédentials LoRaWan doivent être fortement sécurisés et configurés sur la chaîne de production par commande AT.
